# Hand Duel

1v1 браузерная дуэль: игроки кастуют заклинания жестами рук перед веб-камерой.
Живой билд: **https://monaxovdulov.github.io/hand-duel/**

Бэкенда нет — вся логика, ML и рендер на клиенте, связь — WebRTC P2P.

## Как играть

1. Открой сайт → «Создать комнату» → «Играть».
2. На экране ожидания — код комнаты, кнопка «Скопировать ссылку» и QR-код. Соперник открывает ссылку (на телефоне проще всего сканировать QR) и жмёт «Играть».
3. После отсчёта «3-2-1-БОЙ» дерись жестами:

| Жест | Заклинание |
|---|---|
| ✊ кулак | Файербол (10 урона) |
| ✌ виктори | Лёд (6, быстрый) |
| 🤟 рок | Шторм (18, медленный) |
| 👍 большой палец | Хил (+8 себе) |
| ☝ указательный | Болт (4, очень быстрый) |
| ✋ ладонь | Щит — отбивает снаряды |
| 🤲 рамка из двух L-поз | Портал — зеркальный барьер, глушит всё |

HP 100 у каждого; кто упал — модалка «ПОБЕДА/ПОРАЖЕНИЕ» с реваншем.
Работает на десктопе и телефоне (лучше вертикально), нужна камера и HTTPS.

## Стек

- **Vite 7 + TypeScript 5** (strict), ES-модули.
- **MediaPipe GestureRecognizer** (`@mediapipe/tasks-vision` 1.0.1) — завендорен в `public/vendor/mediapipe/` + `public/models/*.task`, не npm-зависимость. Типы вручную в `src/mediapipe.ts`, загрузка динамическим `import()` по абсолютному URL.
- **three.js** — вся сцена в одном WebGL canvas: видео-панели, снаряды с трейлами, щит, портал (свой шейдер), вспышки.
- **trystero 0.25** (nostr-стратегия) — P2P: data-экшены (`cast/block/hp/ko/rematch`) + видеострим камеры.
- **`@vitejs/plugin-basic-ssl`** — только dev: камера на телефоне по LAN требует HTTPS.
- Деплой — GitHub Pages через Actions (`.github/workflows/deploy.yml`), чистый статик.

## Архитектура

```
камера → Tracker (Web Worker, ImageBitmap transfer) → GestureRecognizer
       → Game.onHands (сглаживание, жесты, щит/портал/касты)
       → Effects (three.js: панели видео, снаряды, эффекты)
       ↔ Session (trystero: экшены + стрим) ↔ соперник
HUD — DOM поверх canvas (hud.ts), раскладка панелей — чистый computeLayout (layout.ts).
```

`src/`:

| Файл | Роль |
|---|---|
| `layout.ts` | Адаптивная раскладка: `stack`/`side` по максимальной площади видео (гистерезис 8%), кроп ≤10%, зоны HUD, `compact` |
| `tracker.ts` / `tracker.worker.ts` | Инференс в воркере, drop-frame при занятости, фолбэк на main thread |
| `spells.ts` | `SPELLS`, `GestureInterpreter` (edge-trigger + кулдауны), `isFrameHand`, `portalQuadPoints` |
| `game.ts` | Логика: ладони, щит, портал, касты, коллизии, HP/KO; `armed`/`locked`, `reset()` |
| `effects.ts` | three.js сцена; `camToScreen()` — единственная точка перевода камера→экран |
| `net.ts` | `Session` над trystero: экшены, `addStream` с переанонсом на join |
| `hud.ts` | HUD и оверлеи фаз (loading/waiting/paused/over), спелбар, тосты |
| `main.ts` | Бутстрап + машина фаз `lobby→loading→waiting→fight→over`, реванш, wake lock |
| `qr.ts` | Минимальный QR-энкодер (byte mode, ECC L) для ссылки на комнату |

## Принятые архитектурные решения

- **Полный serverless.** Сигналинг — публичные nostr-релеи через trystero, данные и видео — WebRTC DataChannel/MediaStream напрямую. Для публичного деплоя достаточно статик-хостинга.
- **Авторитетность по своему HP.** Урон по себе каждый клиент считает сам и рассылает `hp`; при 0 шлёт `ko`. Блок считает защищающийся, атакующему уходит `block` только для визуала.
- **MediaPipe завендорен, не npm.** Воркер не умеет резолвить пути от страницы — бандл и wasm под `public/`, грузятся абсолютным URL; GPU-делегат с фолбэком на CPU.
- **Системы координат.** Лендмарки в сыром пространстве камеры (не зеркальны); перевод в экран только через `camToScreen()` (учитывает кроп и селфи-зеркало). По сети `cast.x` — зеркальный x отправителя, получатель зеркалит обратно.
- **Адаптивная раскладка, а не сплит пополам.** `computeLayout()` выбирает ориентацию по площади видео с гистерезисом 8% (не дёргается при ресайзе), панели contain-fit с кропом ≤10% — видимая область почти совпадает с областью трекинга. В `side` соперник слева.
- **Явная машина фаз** вместо размазанных статусов: lobby → loading → waiting → fight → over; каждый оверлей виден только в своей фазе. Отсчёт «3-2-1-БОЙ», реванш по обоюдному `rematch`.
- **HUD в DOM, не в WebGL** — таблички, спелбар, тосты и модалки обычными элементами, позиционируются по прямоугольникам из `LayoutResult`.
- **Реванш без нового соединения:** комната живая, `Game.reset()` + отсчёт, когда оба нажали.

## Разработка

```bash
npm run dev    # https://localhost:5173 (+ LAN, self-signed HTTPS)
npm run check  # tsc --noEmit
npm run build  # dist/ — то, что уезжает на Pages
```

Локальная игра вдвоём: две вкладки с одним `?room=код`, либо телефон в той же Wi-Fi по LAN-адресу (нужно разрешить порт в файрволе и принять self-signed сертификат).
